#!/bin/bash
# Windows Setup Instructions
# Run: setup_windows.bat (on Windows) or setup_windows.py (with Python)

## Quick Start on Windows

### Option 1: Using Batch File
```batch
cd d:\luv\NS3-TCP-Comparison
setup_windows.bat
```

### Option 2: Using Python
```bash
cd d:\luv\NS3-TCP-Comparison
python setup_windows.py
```

### Option 3: Manual Installation
```bash
pip install matplotlib numpy pandas scipy seaborn
```

## After Setup: Test the Plotting Tool

```bash
cd d:\luv\NS3-TCP-Comparison
python python-analysis/plot_graphs.py
```

This will generate sample graphs in `results/` folder:
- throughput_comparison.png
- delay_comparison.png  
- packet_loss_comparison.png
- pdr_comparison.png
- all_metrics_comparison.png
- summary_results.csv

## Next: Transfer to Ubuntu

Once you run the NS-3 simulations on Ubuntu, copy the output files to Windows:

```bash
# On Ubuntu terminal:
scp -r ~/ns3-workspace/ns-3/*-metrics.txt user@windows-machine:d:/luv/NS3-TCP-Comparison/data/
```

Then run the plotter again to visualize real data.
